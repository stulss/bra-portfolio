# 기획
대상은 3분 동안 이야기를 읽는 채용 담당자. 첫 화면은 이름·한 줄 소개, 본문은 고난 → 재시도 → 지금, 그 뒤 기록·대표작·지원 문서다.

## 시각 체계 (2026-09-10 개편)
이 사이트의 재료는 "못 한 날이 남아 있는 기록"이다. 그래서 리추얼 상태값을 그대로 시각 체계로 삼는다.

- **상태는 색이 아니라 모양**: `못 했다` ○ / `일부 실천했다` ◐ / `실천했다` ●. 색맹 사용자도 구분할 수 있고, 상태에 좋고 나쁨의 색을 입히지 않는다.
- **"아직 없음"에 고유한 형태**: 미확인 숫자 칸과 13번 앱 자리에 같은 빗금 패턴을 쓴다. 없는 것을 숨기지 않고 형태로 남긴다.
- **파란 잉크(`--pen #1f3fa8`)는 다시 시작한 지점에만**: 첫 화면의 재시도 연결선, 재시도 요약 블록, 포커스 링. 그 외에는 쓰지 않는다.
- **첫 화면 = 실제 기록 두 줄**: 2026-08-12(못 했다) → 2026-08-13(일부 실천했다). 문구가 아니라 데이터로 주장을 연다.
- **이야기 = 세로 척추**: 날짜·상태·능력이 왼쪽 레일에, 본문이 오른쪽에. 레일 경계선이 13주의 시간축이 된다.

색: `--paper #edf0ec` · `--sheet #f8faf7` · `--ink #1d2a24` · `--muted #63706a` · `--rule #d3dad2` · `--pen #1f3fa8`.
글꼴: IBM Plex Sans KR 한 가족(300/400/600), 날짜·숫자는 tabular figures. 별도 monospace를 쓰지 않는다.

개편 전 화면은 크림색 종이 + 주황 포인트 + `01 / STORY` 대문자 라벨 + 회전한 메모지 + `보기 ↗` 화살표였다. 어느 과제에 붙여도 말이 되는 기본값이라 걷어냈다. 글꼴은 Google Fonts에서 받으므로 오프라인으로 ZIP을 열면 `Malgun Gothic`/`Apple SD Gothic Neo`로 대체된다. 레이아웃과 상태 표식은 대체 글꼴에서도 그대로 동작한다.

Python 표준 라이브러리로 공개용 JSON → 결정론적 집계·후보 → 정적 HTML을 생성한다. 후보와 승인 본문은 분리한다. 로그인·댓글·통계·외부 API는 없다. 기존 리추얼 원본과 소설은 읽기 전용으로 보존한다.

검증: 동일 입력 전체 산출물 SHA256 일치, ZIP을 새 폴더에서 실행, 미승인 후보 게시 차단, 잘못된 날짜·중복·수치·HTML 주입 검사. 공개 여부는 작성자 문장과 개인정보 검토 이후 확정한다.
