# 기획
대상은 3분 동안 이야기를 읽는 채용 담당자다. 첫 화면은 이름·한 줄 소개와 실제 업무 습관, 본문은 세 능력의 변화와 근거 기록, 대표작·지원 문서·연락 순서로 읽힌다.

## 시각 체계 (2026-09-16 최신 레퍼런스 반영)
이 사이트의 고유한 재료는 여러 현장에서 일이 겹칠 때 `10초 멈추고 → 처리 순서를 적고 → 끝난 뒤 실제와 계획을 대조하는` 습관이다. 화면도 이 순서를 중심으로 설계했다.

- **고정 소개 축**: 데스크톱 왼쪽에는 이름·분야·메뉴·이메일만 남기고 오른쪽에서 이야기를 읽는다. 태블릿과 모바일에서는 상단 메뉴로 바뀐다.
- **첫 화면의 한 가지 강한 장면**: 실제 리추얼에서 확인된 `10초`를 크게 두고 세 행동만 보여 준다. 장식용 이미지와 자동 애니메이션은 쓰지 않는다.
- **카드 대신 작업 행**: 능력 변화는 대조표, 프로젝트는 긴 작업 행으로 표현한다. 동일한 카드가 반복되는 템플릿 인상을 없앴다.
- **실제 근거를 선택해서 공개**: 세 능력은 바로 읽고, 긴 기록 6개는 필요할 때만 펼친다. 프로젝트는 완료한 10번과 비워 둔 13번만 둔다.
- **반응형 기준**: 1020px 이하에서 고정 축이 상단으로 이동한다. 900px 이하에서 능력 표를 3열로 재배치하고, 720px 이하에서는 모든 내용을 한 줄 흐름으로 바꾼다.

색: 차가운 회색 `#f1f3f6`, 먹색 `#16191d`, 업무 표시용 파랑 `#1746e0`, 직접 표시한 흔적처럼 쓰는 노랑 `#f4df45`.
글꼴: 제목은 Gowun Batang, 본문은 IBM Plex Sans KR. 인터넷 없이 열면 Batang·Malgun Gothic 계열로 대체된다.

## 조사한 레퍼런스와 적용 판단
- Tarik Karahodžić의 포트폴리오: 조용한 타이포그래피, 프로젝트 행, 한 가지 강조색, 제한된 움직임을 참고했다. 크림색과 영문 대형 문구는 복사하지 않았다.
- One Page Love의 Endless 소개: 고정된 왼쪽 정보 축과 긴 스크롤 구조를 참고했다.
- Shirley Xu 포트폴리오 사례: 기능 목록보다 생각의 순서를 보여 주는 서사 구조를 참고했다.
- Creative Bloq의 2026 포트폴리오 인터뷰: 시각적 과시보다 속도·명료성, 적은 대표작, 결과와 함께 사고 과정을 보여 주라는 기준을 적용했다.

Python 표준 라이브러리로 노션 리추얼 DB → 공개용 JSON → 결정론적 집계·후보 → 정적 HTML을 생성한다. 노션 토큰은 환경변수에서만 읽고, 이미 사람이 고른 근거 문장은 자동 동기화가 덮어쓰지 않는다. 후보와 승인 본문은 분리하며 기존 리추얼 원본과 소설은 읽기 전용으로 보존한다.

검증: 동일 입력 전체 산출물 SHA256 일치, ZIP을 새 폴더에서 실행, 미승인 후보 게시 차단, 잘못된 날짜·중복·수치·HTML 주입 검사. 공개 여부는 작성자 문장과 개인정보 검토 이후 확정한다.
