# 제출용 문구

## 재현·통과 확인 4가지

### 1. 공개 결과물 접속

- **어디서 확인하나요?** 공개 결과물 URL `https://hongjuhyung.vercel.app`
- **무엇을 하나요(3단계 이내)?** ① 시크릿 창을 엽니다. ② 공개 URL을 입력합니다. ③ 첫 화면의 이름·한 줄 소개·이메일을 확인합니다.
- **무엇이 보이면 통과?** 로그인 화면 없이 홍주형의 소개와 `doffl9737@gmail.com`이 보이면 통과입니다.
- **안 될 때:** 주소를 다시 붙여넣고 새로고침합니다. 그래도 열리지 않으면 다른 브라우저에서 확인합니다.

### 2. 세 능력과 기록 숫자 확인

- **어디서 확인하나요?** 공개 결과물의 **세 능력**, **기록 장치** 메뉴
- **무엇을 하나요(3단계 이내)?** ① **세 능력**을 누릅니다. ② 자기조절력·대인관계력·자기동기력의 처음·반복한 행동·지금을 읽습니다. ③ **기록 장치**를 눌러 숫자를 확인합니다.
- **무엇이 보이면 통과?** 세 능력이 실제 경험과 함께 설명되고, 기록 숫자에 26일·52회가 보이면 통과입니다.
- **안 될 때:** 페이지를 새로고침한 뒤 메뉴를 다시 누릅니다. 숫자가 다르면 최신 기록으로 다시 빌드한 결과인지 확인합니다.

### 3. 대표작 논문 확인

- **어디서 확인하나요?** 공개 결과물의 **대표작** 메뉴와 **논문 읽기** 링크
- **무엇을 하나요(3단계 이내)?** ① **대표작**을 누릅니다. ② 10번 과제의 **논문 읽기**를 누릅니다. ③ 제목·문단·표가 문서 형태로 보이는지 확인합니다.
- **무엇이 보이면 통과?** 10번 논문이 Markdown 기호 없이 읽히고, 13번 앱은 예정 자리로 남아 있으면 통과입니다.
- **안 될 때:** `https://hongjuhyung.vercel.app/paper.html`을 직접 열어 새로고침합니다. `#`, `|---|` 같은 기호가 그대로 보이면 통과하지 못한 것입니다.

### 4. 기록 갱신 장치 재현

- **어디서 확인하나요?** 제출 파일 `기록갱신장치.zip`
- **무엇을 하나요(3단계 이내)?** ① ZIP을 풉니다. ② 압축을 푼 폴더에서 터미널을 엽니다. ③ `python build.py --no-sync --input input --output preview`를 실행합니다.
- **무엇이 보이면 통과?** 오류 없이 실행되고 `preview/index.html`이 새로 만들어지면 통과입니다.
- **안 될 때:** Python 3 설치 여부와 현재 터미널 위치가 압축을 푼 최상위 폴더인지 확인한 뒤 같은 명령을 다시 실행합니다.

## AI와 나의 판단 세 줄

1. AI에게 맡긴 일: 이력서·리추얼·논문 자료를 대조하고, 소개 사이트와 기록 갱신 장치·지원 문서의 초안을 만들고 테스트하게 했습니다.
2. 내가 직접 판단한 일: 공개할 이름과 이메일, 10번 과제만 대표작으로 싣는 범위, 사이트에서 날짜와 미확인 항목을 빼는 결정을 제가 했습니다.
3. AI 제안을 따르지 않은 일: 기록만 강조한 한 줄 소개와 근거 없는 출석·제출 칸은 쓰지 않고, 실제 경력과 확인된 기록을 중심으로 다시 고쳤습니다.
