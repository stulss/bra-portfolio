## 학생 자체 점검 및 과정 항목
- [ ] 소설의 힘 있는 세 장을 고르고 본인이 읽어 확인 (후보: 15·16·17장)
- [ ] 9번 서사·리추얼과 비교해 각색을 사실로 되돌리기 (AI 대조 완료, 본인 확인 대기)
- [ ] 약 1,500자 본편 검토 및 세 능력 장면 확인
- [x] 한 줄 소개 세 후보 중 본인이 고르고 직접 작성 (후보를 고르지 않고 본인 문장으로 새로 작성)
- [ ] 첫 문장과 마지막 문장 직접 작성
- [ ] 토막마다 날짜가 있는 장면으로 시작
- [ ] 동료에게 같이 일하고 싶은 이유 한 가지 받기
- [ ] 숫자 하나를 고난 장면과 짝짓기
- [ ] 출석·리추얼·제출 현황 각각 원본 대조
- [ ] 논문 시크릿 접근과 앱 예정일 기입
- [ ] 지원 문서 이름·연락처 하나·과제·기간 및 세 능력별 STAR 확인
- [ ] 장치 두 번 실행·새 폴더 재현 확인
- [ ] 후보의 날짜·근거·승인 내용만 반영 확인
- [ ] 사이트·문서·ZIP 개인정보 최종 점검
- [ ] 제출 URL 한 개·파일 무암호 열기·검증 방법·AI 3줄 확인

번호 앞 BRA- 접두사는 표에서 생략했다. 출석률·수료·제출 완료를 리추얼 존재만으로 추정하지 않는다.
