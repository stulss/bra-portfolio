## 배포·디자인 개편 (2026-09-10)
- **Vercel 배포별 URL이 로그인 화면으로 넘어갔다.** `vercel deploy`가 출력한 `hongjuhyung-<해시>-stuls.vercel.app`을 익명 curl로 열자 302 → `vercel.com/sso-api`. Deployment Protection이 배포별 URL에만 걸려 있었다. 별칭 `hongjuhyung.vercel.app`은 200. 제출 URL을 별칭으로 고정하고 두 문서에 경고를 남겼다. 이걸 모르고 냈으면 BRA-C13에서 그냥 떨어졌다.
- **재배포하면 URL이 바뀔 뻔했다.** Vercel 프로젝트 링크(`.vercel/project.json`)가 매번 다시 만드는 `tmp/hongjuhyung/` 안에만 있었다. 폴더를 지우고 다시 올리면 새 프로젝트가 생긴다. 링크를 `.vercel-project.json`으로 루트에 빼고 재배포를 한 줄 명령으로 고정했다.
- **숫자 칸이 5+1로 깨졌다.** `grid-template-columns:repeat(auto-fit,minmax(190px,1fr))`가 1440px에서 5칸을 만들어 6번째가 혼자 남고 옆에 회색 덩어리가 생겼다. 항목이 6개로 고정이므로 `repeat(3,1fr)`(태블릿 2, 모바일 1)로 바꿨다. auto-fit은 개수가 유동적일 때 쓸 것.
- **PDF에서 장면 제목만 페이지에 남았다.** `.scene`을 CSS Grid로 짜고 `break-inside:avoid`를 걸었는데, 크롬은 grid 컨테이너의 페이지 분할을 제대로 막지 못한다. 2쪽 끝에 "반응하기 전, 10초를 확보합니다." 제목만 남고 본문이 3쪽으로 넘어갔다. `@media print`에서 `.scene{display:block}`으로 되돌리고 레일을 가로 배치하자 해결. 화면 레이아웃은 그대로 두고 인쇄만 블록으로 바꾸는 방식이다.
