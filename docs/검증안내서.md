## 주의: 제출할 URL을 헷갈리지 말 것
Vercel의 **배포별 URL**(`hongjuhyung-<해시>-stuls.vercel.app`)은 Vercel Authentication이 걸려 있어 로그인 화면(302 → vercel.com/sso-api)으로 넘어간다. 이 주소를 제출하면 BRA-C13에서 탈락한다.
**제출은 반드시 별칭 주소 `https://hongjuhyung.vercel.app`** 로 한다. 이 주소는 익명 요청에 200을 반환한다.

현재 사이트는 상단에 "작성자 검토용 초안" 배너가 있다. 작성자가 한 줄 소개·첫 문장·마지막 문장을 직접 쓰고 사실 확인을 마치면 `--publish` 로 재배포하여 배너가 사라진다.
