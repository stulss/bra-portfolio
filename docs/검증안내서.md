# 짧은 확인 방법

## 30초 확인

먼저 프로젝트 폴더에서 `python build.py --input input --output preview`를 실행해 `Notion sync OK`와 생성 완료 문구를 확인합니다.

1. 현재 수정본은 `http://127.0.0.1:8766`에서 확인합니다. 최종 재배포 뒤에는 새 시크릿 창에서 `https://hongjuhyung.vercel.app`을 열어 로그인 없이 같은 화면이 나오는지 확인합니다. 첫 화면에 이름 **홍주형**, `…한 사람`으로 끝나는 소개, 이메일 링크가 보이면 됩니다.
2. 메뉴에서 **세 능력 → 기록 장치 → 대표작**을 차례로 봅니다. 자기조절력·대인관계력·자기동기력의 변화, 기록 숫자 4개, 10번 논문과 비어 있는 13번 앱 자리가 있습니다. **논문 읽기**를 누르면 Markdown 기호가 아닌 제목·문단·표 형태로 열립니다.
3. **지원 문서 열기**에서 이력서·자기소개서·경력기술서를 확인합니다. 기록 장치는 `submission/device.zip`, 지원 문서는 `output/pdf/지원문서_홍주형_검토용.pdf`이며 둘 다 비밀번호 없이 열립니다.
